Pages

Reads the list, then follows the “Next” link and repeats. Blank = go to the last page (a wide search can be 140 pages × 25 jobs).

Company profiles

Employees is on no job card, so the recruiter’s profile page is opened once per company. Few Reed profiles publish a headcount — a sample is read first and the rest are skipped if it comes back empty. Turn it off and the column stays blank.

Speed

Requests running at the same time. Drop to 2 if the console shows 403 or 429.
